# Tubos-sonoros
Este cuaderno reúne los conceptos fundamentales relacionados con el comportamiento del sonido en tubos. Inicia con una introducción sobre la naturaleza del sonido y la formación de ondas sonoras. Luego desarrolla el estudio de los tubos sonoros.

Este cuaderno fue elaborado por Tiara Santana con fines académicos y educativos. Se permite su consulta y uso para estudio, siempre que se reconozca la autoría correspondiente. Queda prohibida su reproducción o presentación como trabajo propio sin autorización de la autora.
